# Online compiler instructions

Use the MongoDB editor at https://www.mycompiler.io/online-mongodb-editor

1. Open the MongoDB editor.
2. Replace the sample code with `scenario-b3-online-compiler.js`.
3. Click Run.
4. The editor is described as a MongoDB 6.0.13 runner. If any administrative command
   (especially `hideIndex`, `unhideIndex`, or `explain`) is restricted by the hosted
   environment, run the corresponding file in local `mongosh`.

This browser editor can help demonstrate Scenario B3. It does not replace a local
replica set or MongoDB Database Tools for Scenario B4.
